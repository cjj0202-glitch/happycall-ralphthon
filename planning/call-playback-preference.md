# 빠른 통화 시연과 재생 속도 유지

2026-09-22 pc1 · 기준 main `3b67bf4` · 사용자 요청: 바쁜 상담원·경영주의 빠른 통화 시연.

## 작은 변경과 소유

현재 기본 속도는1배이며 `Desk`와 음원 세션이 접수마다 다시 만들어져 선택한 배속도 초기화됩니다. 사용자에게 필요한 결과는 기본1.25배 청취와 선택한 배속의 일관된 유지입니다. CLOVA 공식 음원 수신·자연스러움 인수는 별도로 남습니다. 기존 음원 원본과 STT 입력을 변경하지 않습니다.

메인이 `page.tsx`와 `CallReview.tsx` 통합을 소유합니다. PC2 N02-M5의 소유는 별도 오프라인 검사기/후보이므로 frontend와 겹치지 않습니다. 신규 검사 `tests/e2e/call-playback-preference-unit.mjs`와 결과 보고를 이 변경에 묶습니다. 새 CSS·폰트·팔레트·메뉴는 추가하지 않고 기존 재생 컨트롤을 사용합니다.

## 상태 계약

- Home에 배속 선호를 두고 Desk→CallReview로 전달합니다. 기본1.25배, 같은 탭에서 사례 선택·WMS/TMS 왕복·역할 이동 후에도 사용자가 고른 값을 유지합니다. 새 페이지를 여는 경우에는 기본값으로 시작합니다. 영속 저장이나 다른 탭의 설정 공유를 추가하지 않습니다.
- 선택값은 UI 이벤트에서 즉시 부모에 전달합니다. 새 오디오가 metadata를 읽을 때도 그 선호를 적용하며 목소리 높이를 보존하는 브라우저 재생을 사용합니다. 원본 WAV·타임라인은 변경하지 않습니다. native ratechange 경로와 잘못된 수치도 검사합니다.
- sourceKey(case/channel/audioUrl)와 재생 attempt key는 유지합니다. 속도 선호만 유지하고 재생 완료·seek·clip·이전 audio 이벤트는 새 사례로 넘기지 않습니다.
- 완료는 기존 trusted ended·처음부터 재생·native played 범위·seek/clip 배제 조건을 유지합니다. wall time이 짧아졌다는 이유로 완료를 합성하지 않습니다. 이미 끝까지 들은 기존 사례의 부모 완료 상태 보존 정책도 변경하지 않습니다.
- 제공되면 전체 통화 예상 청취 시간을 duration/rate로 계산해 ‘약’으로 표시할 수 있습니다. 이 값은 실제 측정 벽시계나 자연스러움/명료도 판정이 아닙니다.

## 구현 전 관측과 검증

읽기 전용 코드 검토자는 실제 TSX를 메모리 실행해 1.25·1.5 × 정상/seek/played공백/가짜ended/구간 10조건을 대조했습니다. 정상만 완료 callback1, 나머지0이며 구간 끝에서 pause했습니다. 실제 브라우저의 배속 증거는 아니고 기존 전체 리허설은1배속 기준입니다.

수정 후 같은 역할·사례 이동의 실제 Home/Desk 전달, 오디오 교체·재시작, 잘못된 배속, metadata/ratechange/구간/seek/이전 이벤트를 정상·음성·경계·변이로 검사합니다. 기존 역할·초안·저장·모바일 동선 검사와 타입검사를 영향 범위로 실행합니다.

메인은 새 서버/브라우저를 만들거나 API를 재시작하지 않고 기존3100 탭에서 HMR을 확인합니다. 저장·분석 호출·초안 초기화 없이22접수와 기존 미저장 초안을 보존합니다. 실제1.25/1.5배 전체 재생·배속변경·사례와 WMS/TMS 왕복·분석 준비 조건을 관측하며 화면3폭과 오류를 확인합니다. 실제 사람 청취와 새 전체 저장/이관 흐름은 이 검증을 대신하지 않습니다. 배포 묶음은 변경된 코드로 별도 새로 생성하고 배포 완료로 표시하지 않습니다.
