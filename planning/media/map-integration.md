# 지도 연동 준비와 현재 경계

2026-09-21 사용자 지정 로컬 시크릿 관리 폴더를 읽기 전용으로 확인했습니다. 그 폴더에는 키 인벤토리와 관리 스크립트가 있으며, 지도 관련 참조로 카카오 REST 연동이 기록돼 있습니다. 네이버 변수도 있지만 이를 지도 서비스 권한으로 해석하지 않습니다. 민감한 값과 내부 경로는 공유 문서에 복사하지 않습니다.

인벤토리는 2026-09-07 관측입니다. 현재 키 유효성·회전 상태·등록 도메인·허용 API·지도 JavaScript용 키는 아직 확인하지 않았습니다. 과거 문서에 REST키와 JS키 혼동 정정이 있어, 외관이나 변수명만으로 브라우저용 키라고 추정하지 않습니다. 사용자 요청은 지도에 필요할 때 이 위치를 참고하라는 것이며 사내 운영 키 회전·운영 설정 변경을 새로 실행한 것은 아닙니다.

## 적용 순서

1. TMS에 지리적 지도가 필요한 결과와 입력을 먼저 확정합니다. 현재 SYN 사례 방문순서는 좌표/GPS 실측이 아닙니다. 독립 합성 좌표를 사용할 때도 실제 배송 추적과 구분합니다.
2. 메인이 로컬에서 실제 설정 출처·키 종류·현재 권한·도메인을 확인합니다. REST secret은 서버 비밀환경값으로만 사용하고 프론트 번들/HTML/문서/로그/편지에 넣지 않습니다. SDK용 브라우저 식별자는 별도 종류와 등록 도메인을 확인해야 합니다.
3. 외부 조회에는 승인된 합성 시연 입력만 사용합니다. 사내 점포 주소/운영 좌표/원천 행을 자동 전송하지 않습니다. 라우팅 결과와 방문 계획/실제 기록은 별도 출처로 표시합니다.
4. 제공사·등록 도메인·권한이 확인되면 제한된 최소 연동을 구현하고 로드실패/권한거부/타임아웃·모바일·출처표시를 검사합니다. 아직 준비되지 않은 지도 API를 완료로 보고하지 않고 현재 방문순서 개요를 유지합니다.

지도 인증·공용 서버/API·배포 환경은 pc1 소유입니다. pc4의 현재 TMS/회귀 카드에 지도 인증 업무를 추가하지 않으며 키를 PC 간 편지로 전달하지 않습니다.
