# 한국어 통화 v5 — 빠른 현장 응대 원고

2026-09-21. 바쁜 경영주와 상담원이 바로 용건을 주고받도록 두 시나리오를 각 10턴으로 다듬었습니다. **각 30~40초는 합성 전 추정 목표이며 실제 길이는 미측정입니다.** 대본·텍스트 대조까지 마친 후보로, 합성·사람 청취·STT·제품 적용은 미실행입니다.

상담원은 CLOVA Dubbing의 제공 보이스 후보 **아나운서 조수빈**(사용자 호칭: 조수연), 경영주는 **승표**입니다. 사용자의 기존 +2 비교 후보에 대한 “더 빠르게”, “특히 승표가 너무 느리다”, “서로 바쁜 현대인” 피드백을 반영했습니다. 내부 voice ID·최종 속도 설정은 미정이며 기존 설정을 적용했다고 기록하지 않습니다. 실제 인물의 상담 참여·추천·보증을 뜻하지 않습니다.

[합성용 JSON](korean-call-v5-fast-script.json)의 스키마 표기는 `oneflow-korean-call-v5-fast-candidate-2`입니다. `text`는 검토용, `spokenText`는 합성 입력용이며 둘 다 실제 전사 결과가 아닙니다. 합성 표시와 가상 점포명을 유지합니다. [기존 v4](korean-call-v4-script.md)는 보존했습니다.
