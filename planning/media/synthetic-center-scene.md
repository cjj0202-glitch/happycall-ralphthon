# 합성 센터 장면 상세설계 v1

2026-09-21 pc1. 사용자 추가 요청에 따라 로컬 센터 도면 PDF 7개/7페이지를 모두 렌더링해 확인하고 30_센터작업모니터링의 현행 parser·router·화면을 대조했습니다. 원본 도면·렌더·추출문·해시는 `.local/layout-study/`에만 보관합니다. 이 문서는 독립 합성 장면의 제작 계약이며 실제 센터 복제나 완성 영상 보고가 아닙니다.

## 관찰과 채택

도면에는 수작업 분류안, RT/DAS 배치안, 직선형/휠 소터 대안, 랙·피킹 구간·출하 대기 구역이 구분돼 있습니다. 여러 안을 한 센터의 확정 설비처럼 합치지 않습니다. 최신 준공 상태·카메라 위치·설비별 실제 동선은 이번 자료만으로 확정하지 않았습니다.

시연은 **랙 옆 피킹 정지 구간 → 소터 투입 → 직선 이송 → 분기 슈트 → 출하 대기 → 도크**로 이해할 수 있게 독립 배치합니다. 피킹 중에는 토트가 구간에 서고 작업자가 랙을 오갑니다. SKU 한 줄마다 토트가 새로 생기거나 랙마다 토트가 이동하지 않습니다. RT/DAS와 소터는 서로 다른 분류 방식으로 구분하고 모든 작업을 하나의 장치라고 부르지 않습니다.

30 모듈의 피킹/분류 기록과 예정·실제 슈트 필드에서 사건 이름과 관계를 참고합니다. 현재 토트 루프 화면은 BCR 이동 로그 대신 피킹 시각으로 구성한 임시 뷰이며, 선행피킹 때문에 **피킹 순서가 실제 토트 이동 순서를 보증하지 않습니다**. 시간×구간 차트 좌표도 평면 좌표가 아닙니다. 원천의 루프의심/구간역행을 실제 역주행 영상으로 바꾸지 않습니다. 출고예정일, 이벤트 시각, 집계 슬롯을 구분합니다.

## 공간·촬영 계약

[scene-layout-v1.json](scene-layout-v1.json)의 미터 단위 좌표·30×18 크기·각도·카메라 위치는 모두 이번 시연을 위해 새로 정한 값입니다. 회사 도면의 치수·좌표·설비 수를 추출한 값이 아닙니다. Blender와 브라우저의 평면 개요는 이 파일의 동일 구역/경로 ID를 사용합니다.

| 영역 | 사용자에게 보여줄 것 | 표현 규칙 |
|---|---|---|
| 피킹 | 랙, 구간 정지 토트, 작업 공간 | 작업자 보행과 토트 이동 분리. 통로를 설비가 막지 않음 |
| 투입·소터 | 투입부, 롤러, 직선 이송, 분기 | 벨트/롤러 높이와 물체 바닥 접촉, 분기 시 회전 연속 |
| 슈트·대기 | CH-02 방향, 출하 대기 구역 | 슈트와 도크는 별도 구역. 전체 연결선은 설명용 |
| CCTV | 높은 고정 시점, 분기 구간 | SYN-CAM-02. 실제 설치 위치·사각지대 분석이라고 하지 않음 |
| 상세 패널 | 시각·상품/수량/단위·토트·출처 | 선택 이벤트와 함께 바뀌며 미확인 값은 그대로 유지 |

3D 결과는 물성·조명·접촉 그림자·롤러/안전 가드를 먼저 다듬습니다. 전체 시설을 작은 화면에 과밀하게 넣지 않고 전체 동선 개요와 선택 공정의 근접 CCTV를 구분합니다. 텍스트는 HTML/영상 후처리로 선명하게 표시하고 브랜드·직원 얼굴·원본 도면 문구를 넣지 않습니다.

## 첫 Bolt: CASE-0002 / W-W3 한 구간

- 사용자 결과: W-W3을 누르면 분기02와 출하 방향, 해당 합성 영상, 등록 시각을 한눈에 대조할 수 있습니다.
- 기록 기준: `2026-09-18T02:33:00+09:00`, CH-02, D-02, SYN-CAM-02. `cases.json`의 같은 사건 값과 대조합니다.
- 12초 시연: 0~3초 직선 접근, 3~6초 분기, 6~10초 슈트 이동, 10~12초 안정된 끝 구간. 실제 설비 속도·소요시간 실측이 아닙니다. 첫 검토는 시작/분기/끝 대표 3프레임입니다.
- **W-W3의 개별 토트 식별은 미확인입니다.** 화면상의 이동 객체는 `SYN-VIS-PARCEL02`이며 업무 토트 연결은 null입니다. 피킹 토트A가 출고 토트B로 바뀌는 장면을 만들어 원인을 단정하지 않습니다.
- 영상 재생 시간은 `시연 +00:06`으로, 기록 시각은 별도의 고정 이벤트 시각으로 표시합니다. 몇십 분의 이벤트 간격을 12초에 압축하면서 실제 CCTV 시계인 것처럼 보이지 않게 합니다.
- 합성 객체 좌표는 `synthetic-scene-ground-truth`입니다. 영상 AI 검출이나 업무상의 연속 추적 증거가 아닙니다.
- 장면에 오류/작업자 귀책을 심지 않습니다. 두 기록의 상품·수량·단위/토트 차이는 UI에서 비교하고 발생 원인은 미확인으로 남깁니다.

## 연결과 예외

공정 선택은 `caseId + eventId + cameraId`를 기준으로 근거 행·장면·영상이 함께 선택됩니다. 업무 객체 ID와 시각화 객체 ID를 별도 보관합니다. 카메라/영상 미등록, 다른 사건, 기준시각 이후, 잘못된 구간, 영상 로딩 실패는 이유와 복구 동작을 보여줍니다. 신규 연결 INT 접수에는 원본 영상이 자동 상속되지 않습니다.

대표 프레임을 확인한 뒤 짧은 동작을 렌더하고 같은 장면/seed로 최종 해상도를 확장합니다. 후보 `.blend`·생성 코드·메타데이터·MP4·SHA를 함께 제출합니다. pc3는 `scripts/media_pc3/`, WmsScene, pc3 overlay/검사/보고만 수정하고 공용 fixture·manifest·부모 화면은 pc1이 인수 후 등록합니다.
