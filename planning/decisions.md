# 제품 회의 결정 대장

여기는 **사람이 내린 제품 결정**의 정본이다. 설치·운영의 기존 결정은 [ops/decisions.md](../ops/decisions.md)에 있다. 아래 초기 항목은 사용자 요청과 검증 사실만 기록하며, 아직 열지 않은 4인 회의를 완료로 만들지 않는다.

| ID | 상태 | 내용 | 근거·결정자 | 다시 열 조건 |
|---|---|---|---|---|
| USER-01 | 확인 | 네 사람이 토론하며 기능 포함/제외와 큰 솔루션 구조를 설계 | 2026-09-21 사용자 요청 | 사용자 방향 변경 |
| USER-02 | 확인 | '볼트'는 BMAD를 뜻함 | 2026-09-21 사용자 직접 응답 | 없음 |
| USER-03 | 확인 | 다른 PC 준비와 새 메인 세션을 위한 채팅용 프롬프트 필요 | 2026-09-21 사용자 요청 | 인수인계 방식 변경 |
| USER-04 | 보류 | Vercel 설정·추가 인증 시도 | 2026-09-21 사용자 보류 요청 | 사용자가 재개 요청 |
| USER-05 | 확인 | 교육의 First Bolt·Journey·Flow·Silent Test도 BMAD와 별개 개념으로 방법론에 반영 | 후속 사용자 제공 5주차 자료, docs/16 출처 한계 참조 | 원본 캡처 대조 결과 |
| USER-06 | 확인 | 현재 준비·검토를 서브에이전트로 병렬 수행 가능 | 2026-09-21 사용자 직접 요청 | 동시 편집 경계 충돌 또는 사용자 중단 |

## 다음 회의의 미결정

- 결정 책임자와 네 사람의 회의 관점/실제 이름
- 첫 사용자와 업무 완료 상태
- OneFlow 이름·미도착/오출 P0 기준선 유지 여부
- 이번 범위와 후속 솔루션 범위
- 실제 제품 API 필요성·예산·권한
- 계약·기술 결정의 검증과 PC별 책임
