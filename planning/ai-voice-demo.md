# AI 합성 통화·전사·정제 시연 설계

**현재 상태:** 이 문서의 후보/호출 전 표기는 작성 당시 설계입니다. DEC-013~015에 따라 사전 합성음성+종료후 실제STT/GPT는 이번 필수 범위입니다. 생성·API접속·의미품질을 분리하며 현재 결과는 ../CURRENT_TODO.md와 ../reports/live-analysis-quality.md를 따릅니다.

2026-09-21, DEC-011·012 반영. 구현 및 API 호출 전 설계이며 성공 증거가 아니다.

## 입력과 처리

1. 91 프로젝트의 33_해피콜분석에서 확인한 실제 문의 패턴을 바탕으로 가상 점포·상품·수량·날짜를 넣어 미도착/오출고 대본을 작성한다. 실제 상세 원문을 외부로 보내지 않고 필요한 업무 패턴만 가상화한다.
2. 상담원과 경영주에 서로 다른 기본 합성 목소리를 지정해 한국어 통화 파일을 생성한다. UI에 AI 합성 시연임을 표시한다.
3. 통화 재생 종료 후 생성된 녹음 파일을 실제 전사 API에 전달한다. 생성용 대본을 결과로 대신 출력하지 않는다.
4. 전사된 발화에서 업무 요약·점포/문의 대상/수량과 단위·요청·누락/모순·추천 부서를 구조화한다. 발화 근거 ID, 불확실성, 상담원 수정 이력을 유지한다.
5. 사람이 조회 대상을 확인하면 별도 WMS·TMS 화면에 같은 케이스의 키로 연결한다. 물류 기록 확인 후 사실/미확인과 센터 회신 초안을 구분한다.

## 확인한 재사용 코드와 모델 후보

33 모듈 조사 결과: 이 PC의 설정상 원천 위치인 `33_해피콜분석/03_데이터/`와 원본 접수 파일은 확인되지 않았다. 대신 `90_산출물/2026-08-25_답변초안_검수요청.md`의 미입고 유선 확인·오출 등록, 오입고 회송 안내 패턴을 확인했다. 과거 답변 집계의 참고이며 개별 접수 원문을 재검증한 사례가 아니다. 합성 대본은 이 패턴을 재구성한 가상 사례라고 표시한다.

- `C:/00.프로젝트/hackathon-ai-kit/scripts/make_voice.py`: OpenAI TTS, WAV 생성·화자별 음성·구간 병합 구현이 있다. 출력 경로는 킷 demo/audio이므로 제품 자산 경로와 명시적으로 연결해야 한다.
- `C:/00.프로젝트/hackathon-ai-kit/scripts/transcribe.py`: 전사 호출이 있으나 기존 화자 추정은 휴리스틱이다. source 모드는 대본 재생이며 실제 STT가 아니다.
- 한국어 TTS 후보: `gpt-4o-mini-tts`, 기본 음성 `marin`/`cedar` 비교 후 선택. 공식 문서는 한국어 지원과 해당 음성 추천을 명시하지만 영어 최적화임도 명시한다. 한국어 상품명·박스/개·숫자 발음을 청취해 결정한다. [공식 TTS 문서](https://developers.openai.com/api/docs/guides/text-to-speech).
- 화자 구분 전사 후보: `gpt-4o-transcribe-diarize`, `diarized_json`. 30초 초과 파일은 `chunking_strategy=auto` 등이 필요하다. 화자 A/B와 상담원/경영주의 역할 식별은 따로 확인하며 불확실하면 사람에게 표시한다. [공식 전사 문서](https://developers.openai.com/api/docs/guides/speech-to-text).
- 정제: 서버의 OpenAI 텍스트 API 어댑터에 전사 결과와 제한된 출력 필드를 전달한다. 모델은 계정 접근·구조화 출력 지원 확인 뒤 고정한다. 키를 브라우저에 넣지 않는다.

## 검증·실패 처리

- 생성 대본은 기대값 검증용 별도 자료이며 전사 정답을 주입하는 입력으로 쓰지 않는다.
- 수량과 단위, 요청 의미, 불만 강도를 보존하고 욕설·무관한 반복을 업무 문장으로 정리한다. STT 자체 오류도 사람이 수정할 수 있게 한다.
- 실패 시 원본과 실패 상태를 보존하고 재시도한다. 저장 결과 재생은 사용자가 선택하고 화면에 재생임을 표시한다.
- 가격·호출 횟수를 고정한 데모 준비 실행 전 비용을 확인한다. docs/18의 데모 전용·25달러 경고·30달러 사전 보고 정책을 유지한다.
- 실제 음성 파일·전사 응답·정제 응답·사람 검토가 확보되기 전 완료로 표시하지 않는다.
