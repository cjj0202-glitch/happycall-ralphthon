# 토론으로 확정한 제품 프롬프트

2026-09-21, DEC-001~015 반영. **제품 요청의 현재 정본 / 실제 Goal 미실행**. 전체 실행 지침은 [통합 작업 프롬프트](../PROMPT_team.md)입니다. 이 문서를 입력·실행한 Goal 원문이나 완료 증거로 취급하지 않습니다.

## 사용자와 이번 결과

경영주의 문의에서 시작합니다. 상담원은 통화와 사이트 문의를 정제·확인·이관하는 주사용자이고, 센터 담당자는 물류 사실·조치 결과 확인과 최종 회신을 담당합니다. 경영주는 사이트에서 등록된 회신을 확인합니다.

이번 해커톤은 **미도착·오출고 × 통화·사이트 텍스트**를 공통 접수 구조에 연결합니다. 문의 접수→근거 조회→사실/미확인 구분→답변 초안→상담원 확인·이관→센터 최종 회신·조치 확인→경영주 조회가 이어져야 합니다. 후속 유형·운영 권한·실시스템 연결·SLA/통계는 솔루션 지도에 보존합니다.

## 통화·텍스트 정제

AI가 합성 대본과 한국어 두 화자 음성을 미리 생성합니다. 통화 재생이 끝난 뒤 실제 음성 인식 API로 전사하고 GPT로 요약·접수서·추가 질문·입력 오류·부서 추천을 생성합니다. 통화 중 실시간 추천은 이번 범위가 아닙니다. 대본을 전사 성공으로 표시하지 않습니다.

경영주 텍스트 제출 화면에서는 원문을 보존하고 STT 없이 같은 구조화 단계로 합류합니다. 기존 두 통화 예시를 텍스트 예시로 대체하지 않습니다.

- 원문/STT, AI 제안, 상담원 수정·확정을 구분합니다. STT도 오류 가능성이 있어 불명확하면 확인 대상으로 남깁니다.
- 욕설은 업무 표현으로 순화하되 요청·불만 강도·반복 주장 등 의미를 보존합니다. 문맥이 불명확한 말을 임의 삭제해 배송 단서를 잃지 않습니다.
- 점포·대상·수량·단위·시각·요청의 누락과 모순을 표시하고 근거 발화/문장 및 확인 질문을 제공합니다.
- 접수 수량·단위는 **문의 대상 상품의 실수령에 대한 경영주 진술**입니다. 주문·피킹·출고 수량과 구분하며 BOX와 EA를 임의 환산하지 않습니다. 실제 수령 미확인이면 null을 유지하고 경영주 주장 자체를 물류 확정 사실로 표시하지 않습니다.
- 상담원 입력과 같은 대상의 최종 고객 진술을 대조합니다. 수량이 같고 단위만 다르면 단위 오류로 표시합니다. 이관 부서는 허용 목록에서만 추천하고 이유·미확인을 보여 줍니다.
- 추가 질문은 통화 후 재확인할 내용이며 자동 재통화·외부 발송이 아닙니다. API 실패·대기·재시도와 명시적 replay를 구분합니다.

## WMS·TMS 화면

해피콜 케이스의 점포·주문·상품·토트/출고·배차 범위를 유지하며 별도 WMS·TMS 화면을 엽니다. 선택한 기록을 케이스 근거로 가져옵니다.

- WMS: 피킹 방식·스캔 시각·존/셀·토트·상품·수량, 소터 분류 시각·예정/실적 슈트·이동, 출고 시각·도크를 표시합니다.
- TMS: 배송 루트의 방문순서·계획 도착·실제 완료 기록을 구분합니다. 방문순서는 GPS 주행궤적이나 실물 인도 증명이 아닙니다.
- 애니메이션과 개념 지도, 합성 물류 영상 1개 이상을 포함합니다. 영상은 공정 설명용이며 실 CCTV·오출 원인 증거가 아닙니다.
- WMS 참고는 **30_센터작업모니터링**, TMS는 **36_자동점착운영**, 문의 패턴은 **33_해피콜분석**입니다. 이전 35_상온센터물류품질 지정은 DEC-014로 정정됐습니다.
- 현재 fixture는 독립 합성 SYN-* 사례입니다. 참고 모듈의 추정 흐름·시간 버킷·기록 의미를 실적처럼 확대하지 않습니다. 실제 시스템 접속이나 장비 제어는 포함하지 않습니다.

## 사람 확인과 종료

점포·문의 대상·담당 부서가 식별되고 상담원이 확인하면 미확인 항목을 보존한 채 이관할 수 있습니다. 대상/부서가 불명확하면 확인 대기입니다. 배송 전체 문의에 상품코드를 강제하지 않습니다. 도착 기록 부재만으로 미도착을 확정하지 않습니다.

센터 담당자가 최종 회신합니다. 남은 확인/조치가 있으면 처리 중을 유지하고 조치 완료와 센터 회신이 있어야 종결합니다. 실제 재배송·재고 변경·보상은 실행하지 않습니다.

## 방법론·검증·공동 작업

도면을 참고한 고품질 CCTV·애니메이션은 [미디어 기준](media/production-quality.md)과 [합성 센터 장면](media/synthetic-center-scene.md)을 따릅니다. 실제 도면·운영값은 로컬에 두고, 기록 지점·설명용 이동·합성 객체 좌표를 구분합니다. 원격 PC 배정은 [docs28](../docs/28_PC_업무배정_기준.md)의 결과·파일 소유·기준 SHA·수용 조건·검증·인계를 함께 전달합니다.

BMAD로 가치·UX·구조·검증을 연결하고, Grill-me로 필요한 핵심 결정만 질문합니다. 교육 First Bolt는 작은 병목 실험→관찰→한 가지 수정→재시험으로 적용하며 Ralph는 배정된 결과를 구현·검증·수정하는 반복입니다. **Dream은 사용자의 의도가 아니며 Grill-me로 정정했습니다. 별도의 Vault 저장소 기능을 요구한 것으로 확대하지 않습니다.**

접수 정제/단위 오류와 물류 사실/미확인 구분을 모두 검증합니다. 사용자는 실제 사람 테스트 대신 Astra Playwright 검증을 먼저 요청했습니다. 기술 검증과 실제 사람 관찰을 구분하고 사용자 네 사람의 동의를 만들지 않습니다. 로컬 병렬 착수는 실제 원격 PC 등록·TEST 완료를 뜻하지 않습니다.

[통합 프롬프트](../PROMPT_team.md)에 공식 배점 활용20·Goal20·결과 중심 위임30·검증30과 실행/증거를 연결했습니다. 예상 점수는 만들지 않으며 원본 로그는 로컬에 보존합니다. 실제 Goal·공식 평가 전체·최종 제출은 별도 완료 증거가 필요합니다. DEC-018에 따라 9/22 09시 배포까지 재확인 없이 진행합니다. 현재 호스팅 대상은 DEC-021의52g Studio/g-28 Vercel이며 docs/12와 실제 계정·저장·배포 검사 기록을 대조합니다. 로그인 성공과 전체 제품 배포 완료는 별도입니다.

실제 진행·남은 일은 [CURRENT_TODO](../CURRENT_TODO.md), API·파일 소유·인수 절차는 [공유 컨텍스트](../docs/21_공유_작업컨텍스트.md)를 확인합니다. 과거 목업/기획 검토는 [참고 검토](../reports/design/reference-planning-review.md)에 있으며 과거 기능·성과를 이번 완료로 자동 승계하지 않습니다.
