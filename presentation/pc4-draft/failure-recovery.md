# N04-D1 실패 시 발표·업무 복구 계획

이 문서는 [5장·300초 발표](storyboard.md)의 조작 계획입니다. **이번 D1에서 제품 UI·서버·브라우저·라이브 AI를 실행한 횟수는 0회**입니다. 아래의 실제 검증란만 기존 실행 증거이며, 계획한 조작을 새 실행·통과로 세지 않습니다. 버전과 실행 주체는 [근거 대응표](evidence-map.md)를 따릅니다.

## 발표 현장 조작 순서

| 실패 상황 | 발표자가 할 순서 — 아직 실행하지 않은 계획 | 계속 보여줄 수 있는 것 | 기존에 실제 검증한 범위와 한계 |
|---|---|---|---|
| 음성이 재생되지 않거나 중간에 멈춤 | ① 재생 실패를 알립니다. ② 같은 사건의 승인 음원인지 확인합니다. ③ 완료가 확인되지 않으면 분석 버튼을 우회하지 않습니다. ④ 같은 사건의 기존 저장 결과·원문 화면 또는 PDF 증거 화면으로 설명을 전환합니다. | 기존 합성 음원/분석 결과라는 표시, 원문과 사람 확인 경계 | pc1 고정 빌드와 pc4 Q2 bfc8543에서 각각 음성 6/6 전체 자연 재생. 끝 seek·구간 재생은 전체 완료가 아님을 검사했습니다. 지금 음성을 듣거나 새 STT를 완료한 것처럼 설명하지 않습니다. |
| STT/GPT 요청 실패·지연·실행 불가 | ① 실패 상태를 유지합니다. ② 자동 유료 재시도하지 않습니다. ③ 같은 사건의 이미 저장된 결과가 있으면 해당 결과의 출처를 표시해 설명하고, 없으면 기존 증거 캡처로 전환합니다. ④ 요청·수량·단위를 원문과 대조하며 불명확한 값은 미확인으로 남깁니다. | 저장된 분석의 원문·AI 제안·사람 수정 구분. 실제 입력 가능한 상태가 확인된 경우에만 수동 접수 경로를 설명 | 이번 복구/정규화 실적은 replay·저장 원응답 재처리이며 새 모델 호출 0입니다. 대본을 실제 전사로 바꾸거나 오류를 새 AI 성공으로 표시하지 않습니다. 자동 필드 128/128도 새 라이브 정확도가 아닙니다. |
| 기존 접수 PATCH 응답 유실·5xx | ① 다시 저장을 누르지 않습니다. ② `저장 여부 확인`으로 같은 접수를 조회합니다. ③ 요청한 내용과 같을 때만 저장 확인 결과를 따릅니다. ④ 다르면 비교 화면에서 `서버 내용 사용` 또는 `내 초안 유지`를 명시적으로 선택합니다. ⑤ 초안을 유지하면 사람 확인을 다시 하고 저장합니다. | 보존된 초안, 현재 서버 내용, 미확정 안내 | pc4 Q3-05/06: 실제 저장 후 응답 유실과 **실제 저장 없는 503**을 각각 검사했습니다. GET 200 자체는 저장 성공이 아닙니다. 서버가 계속 끊겨 조회도 실패하면 저장 완료로 진행하지 않습니다. |
| 경영주 신규 접수 POST 응답 유실 | ① 새 문의를 다시 만들지 않습니다. ② `접수 저장 여부 확인`을 사용합니다. ③ 미확정 조회 이후 제품이 제공한 `같은 내용으로 접수 확인·재시도`만 사용합니다. ④ 원래 사례가 확인될 때까지 본문과 시도 키를 바꾸지 않습니다. | 입력 보존·잠금, 기존 접수 조회 결과 | pc4 Q3-03에서 실제 POST201 저장 후 응답만 유실, 조회404 실패 주입, 같은 키·본문의 실제 재시도로 신규 정확히 1건을 확인했습니다. 404는 이 반례에서 실제 미저장이 아니라 의도한 브라우저 실패 주입입니다. 키를 채팅·발표자료에 붙이지 않습니다. |
| 다른 담당자 변경으로 409 | ① 충돌 안내를 유지합니다. ② 최신 내용을 조회·대조합니다. ③ 서버 사용 또는 초안 유지를 선택합니다. ④ 유지 직후 다시 바뀌어도 자동 덮어쓰지 않고 다시 대조합니다. | 두 버전의 요청·회신과 명시적 선택 | pc4 Q3-07에서 실제 UI 409 두 번, 제3자 revision2·로컬 초안 보존을 확인했습니다. Q3-04의 같은 키/다른 본문 409는 실제 공개 HTTP 검사이며 UI 409 표시 검사는 아닙니다. |
| API/네트워크가 완전히 끊김 | ① 연결 실패와 마지막 조회 상태를 알립니다. ② 제품이 보여주는 기존 자료가 있다면 읽기 전용 범위만 설명합니다. ③ 새 접수·저장·이관·종결을 성공으로 진행하지 않습니다. ④ 연결이 돌아온 뒤 서버 조회·대조를 선행하며, 발표 중 복구되지 않으면 기존 PDF/캡처로 전환합니다. | 확인 가능한 기존 합성 화면·실행 결과, 아직 저장되지 않았다는 안내 | pc1 오프라인 읽기 전용 **1/1 PASS**, 오프라인 전체 처리 **0/1 BLOCKED**. pc4 Q2의 offline/API 오류 복구도 영구 오프라인 업무 성공을 뜻하지 않습니다. 이 발표 전환 계획 자체는 새 리허설하지 않았습니다. |
| 합성 CCTV 404·해시 오류·좌표 불일치 | ① 다른 사건의 영상으로 바꾸지 않습니다. ② 같은 등록 영상의 명시적 재시도가 가능할 때만 사용합니다. ③ 해결되지 않으면 같은 사건의 WMS/TMS 기록·출처와 미확인을 보여줍니다. ④ 실제 작업 원인·귀책은 단정하지 않습니다. | 승인된 기존 자료와 기록/미확인 구분, 영상이 없는 이유 | pc4 Q2 bfc8543의 등록 영상 404 복구를 포함한 경계 15/15. 새 CCTV 컴포넌트 수정본은 브라우저 0/1 NOT_RUN이며 960×540 영상과 1280×720 후보 좌표의 실제 정합은 미완료입니다. 과거 영상 검증을 새 3D 자산 검증으로 쓰지 않습니다. |
| 탭 새로고침·브라우저 종료로 초안이 이미 사라짐 | ① 더 이상 복원이 가능하다고 안내하지 않습니다. ② 서버에 저장된 버전만 다시 조회합니다. ③ 유실된 미저장 내용은 원문과 사용자 확인으로 재작성해야 한다고 설명합니다. ④ 발표는 기존 복구 화면으로 전환합니다. | 마지막으로 서버에서 확인한 저장 내용 | 메모리 초안은 메뉴·사례 왕복 보존 범위입니다. beforeunload 경고를 취소한 보존과 강제 종료 후 복원은 다릅니다. **사라진 미저장 초안의 자동 복원은 지원하지 않습니다.** |

표의 ‘기존 저장 결과’는 사건·점포·시각이 일치하고 실제로 보유한 결과에 한정합니다. 없는 결과를 생성해 보였다고 하거나 다른 사건의 근거를 대신 연결하지 않습니다. 조회 자체가 실패한 상태에서 화면의 오래된 값만 보고 최신 서버 상태라고 단정하지 않습니다.

## P2 성공 알림 잔류를 숨기지 않기

pc4 Q3 c6f734f의 [실제 390px 화면](../../reports/pc4/q3-run-20260921T123023563161Z/Q3-08-q3-08-uncertain-390.png)에는 이전 성공 토스트와 현재 저장 미확정 안내가 함께 있습니다. 첫 PATCH는 21:30:50.339 revision1로 성공 응답을 받았고, 두 번째 PATCH는 21:30:50.779 revision2로 실제 저장된 뒤 응답만 유실됐습니다. 저장·편집 잠금은 유지됐지만 이전 성공 문구가 최대 6초 남는 UI 혼선은 **P2 미완료**입니다.

발표자는 녹색 토스트만으로 현재 변경의 저장을 선언하지 않고 미확정 배너와 같은 사례의 조회·내용 대조를 따릅니다. 직전 성공 뒤 실제 미저장 503에서도 이전 토스트가 남을 가능성은 코드에서 확인한 추론이며, 그 조합을 별도 브라우저로 재실행하지 않았습니다. 알림이 시간 경과로 사라졌다는 사실도 제품 수정·P2 해결 증거가 아닙니다.

요청 근거화에는 별도의 P2도 남습니다. `배송 시각을 알려 주세요. 배송 상품 반송 요청은 취소합니다.`에서 공통어 때문에 시각 요청까지 null로 지울 수 있습니다. 원문 대조와 사람 수정을 유지하며, 이를 자동 의미 판별 완료로 발표하지 않습니다.

## 발표용 짧은 설명과 인수 범위

> “응답을 못 받았다고 저장 실패로 단정하지 않습니다. 초안을 보존하고 서버 결과를 먼저 확인합니다. 연결이 끊긴 상태에서는 기존 자료의 읽기와 미확인 안내까지만 가능하며, 저장 완료로 진행하지 않습니다. 지금 보시는 복구 화면은 고정 버전에서 실제 검사한 기존 증거입니다.”

이 계획은 실제 제품 사용성·사람 청취·발표 시간 리허설·최종 배포 검증을 대신하지 않습니다. main e1ef36f 기준 Vercel 로그인과 g-28 링크는 완료됐지만 Blob 생성403 및 계정 조회 연결 저장소0이 남아 있습니다. 배포 준비·실제 배포·영속 저장 완료를 서로 바꾸어 쓰지 않습니다. 새 검사·설치·배포·과금 호출·원문 로그 복사는 본 카드에 포함하지 않았습니다.
