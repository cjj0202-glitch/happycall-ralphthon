# 해피콜 랄프 루프 — Codex

이 파일의 실제 위치에서 세 단계 위가 저장소 루트다. 링크를 통해 발견했으면 실제 대상을 먼저 확인하고 모든 CLI를 해당 루트에서 실행한다.

1. [AGENTS.md](../../../AGENTS.md)를 읽고 `python channel/whoami.py`로 슬롯을 확인한다. 미등록이면 중단하고 hostname을 보고한다.
2. 공유 원본 [.claude/skills/ralph-loop/SKILL.md](../../../.claude/skills/ralph-loop/SKILL.md)를 읽는다.
3. 맡은 작업·완료 조건·중단 조건을 확정한 뒤 한 덩어리씩 실행한다. 구현과 검증 완료를 구분하고, 워커는 증거를 제출하고 pc1이 ops/tasks.py accept로 검증한 항목만 TODO에 체크한다. 공식 Goal·로그 요구는 docs/09와 docs/10을 따른다.
4. `watch`의 출력은 알림이다. 벨만으로 종료된 Codex 작업이 재개되지는 않는다. 재개가 필요한 사용자의 요청에는 지원되는 자동화 기능을 사용하고, 변화가 없으면 알리지 않는다.

작업이 없거나 범위가 모호할 때 무한 루프를 만들지 않는다. 기존 워커나 감시기가 동작 중인지 확인하여 중복 실행을 피한다.
