# WMS 이벤트와 AI 합성 CCTV 연결

작성: 2026-09-21 · 대기세션1

## 범위와 정보 구조

`LogisticsView.tsx`와 `LogisticsView.module.css`에서 기존 주문·수령·스캔 대조, 작업 이벤트, 근거 연결을 유지하며 이벤트별 영상 열기를 제공한다. 등록 영상은 실제 CCTV가 아닌 AI 합성 공정 설명이다. 현재 12초 소터 영상은 CASE-0002의 W-W3(02:33 분기 이동)에만 연결한다. 피킹·출고 영상을 촬영·생성했다고 간주하지 않는다.

1. 작업 이벤트의 시각·위치·원천을 먼저 표시한다.
2. 영상이 연결된 이벤트에 카메라·이벤트 ID·근거 시각·구간과 `AI 합성 CCTV 구간 보기`를 표시한다.
3. 클릭하면 등록 영상과 원본 이벤트·피킹·출고 스캔을 비교하는 팝업을 연다. 모바일에서는 위아래로 배치한다.
4. 피킹 비스킷 18 EA와 출고 휴지 1 BOX의 차이는 원본 스캔의 관측 차이로 표시한다. 발생 공정이나 작업자 귀책으로 변환하지 않는다.

## 매칭 계약

입력은 사례의 `media` 배열이다. `id`, `caseId`, `system`, `cameraId`, `eventIds`, `url`, `synthetic`, `startSeconds`, `endSeconds`, `occurredAt`을 소비한다.

- 사례 ID, 시스템(WMS), 이벤트 ID가 모두 일치해야 한다.
- `synthetic === true`, 같은 사이트의 자산 경로, 유효한 시작·종료 초(0 ≤ 시작 < 종료), 조회 기준 이전 `occurredAt`이 필요하다.
- 이벤트도 기존 asOf 필터를 통과해야 한다. 날짜나 구간이 부정확한 연결은 표시하지 않는다.
- 다른 사례·다른 시스템·미등록 이벤트에 공용 영상을 대체 연결하지 않는다.
- 영상 시각과 이벤트 시각을 별도 표기한다. 등록된 전체 구간은 설명용이며 실제 물류 이동의 시간 동기화를 주장하지 않는다.

## 상태·CTA·실패 동작

| 상태 | 사용자 표시와 동작 |
|---|---|
| 등록됨 | 이벤트 CTA와 연결 영상 목록에서 동일 팝업 열기 |
| 미등록·매칭 실패·미래 기록 | 영상 미등록; 기존 스캔과 근거 확인 유지 |
| 팝업 열림 | AI 합성/실 CCTV 아님, 카메라·이벤트·각 시각·구간, 스캔 비교 |
| 재생 준비 | 사용자 재생 조작; 등록 시작점으로 이동, 종료점에서 정지 |
| 재생 실패·잘못된 구간 | 실패 문구와 다시 불러오기; 원본 스캔 계속 제공 |
| 닫힘 | 닫기 버튼·Escape·배경 클릭, 원래 CTA에 포커스 반환 |
| 사례·시스템 변경 | 팝업 상태 해제; 새 사례에서 연결을 다시 판정 |

## 수용 기준

- W-W3 클릭에서 CASE-0002/SYN-CAM-02/02:33/AI 합성이 일치한다.
- CASE-0001, TMS, W-W1·W-W2·W-W4에는 연결 영상을 재사용하지 않는다.
- 원본 피킹·출고 상품·수량·단위를 별도 표시하고 단위 환산이나 귀책 확정을 하지 않는다.
- Escape와 닫기 후 CTA 포커스를 복구한다. 키보드 포커스는 열린 native dialog 안에 제한된다.
- 영상 오류 시 스캔 조회가 가능하며 재시도할 수 있다.
- 기존 표, asOf 필터, 근거 연결 callback과 모바일 표 내부 스크롤을 유지한다.
- 타입 검사와 읽기 전용 브라우저 클릭 검수를 수행한다. 상담 CASE 상태 PATCH·replay 및 유료 AI 호출은 검수에 사용하지 않는다.

## 후속 확장

피킹·출고 구간은 해당 공정을 묘사하는 AI 합성 자산과 독립적인 이벤트 연결 정보가 준비된 후 추가한다. 현재 미등록 상태를 완료로 보고하지 않는다.
