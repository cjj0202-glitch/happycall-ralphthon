# 관객 속도 시연 영상 — 최종 음성 보완 대기

기존 132초 영상이 너무 빨라 흐름을 따라가기 어렵다는 사용자 피드백을 반영했다. 실제 화면 조작을 다시 녹화했고 편집 가속 없이 299.775초를 유지한다. 클릭 전후 여유, 결과를 읽는 3~4.5초, 더 큰 한국어 자막과 키워드 색상, 단계 표시를 추가했다. 상시 AI 더빙 푸터는 제거하고 마지막 4초 상단에만 CLOVA 출처를 표시한다.

## 완료한 것

- 로컬 격리 API 8128에서 두 사례를 접수부터 센터 중간 회신·경영주 수신까지 실행했다. 기존 사용자 API 8112 상태는 변경하지 않았다. replay 시연이며 새 유료 API 호출은 하지 않았다.
- 클릭 39회, 스크롤 30회. 통화 2개 1.25배, CLOVA 해설 11개 원속도. 새 A~F 해설 6개 모두 포함되어 있다.
- Blender 영상 12초 완주, 분기와 슈트 버튼을 실제로 클릭하고 각 장면에 3초, 업무 기록 대조에 4.5초 머물렀다.
- 1920×1080 H.264 25fps/AAC, 7,487프레임 전체 디코드 성공. 13개 음성의 앞뒤 26개 기준점을 PCM 대조했고 최대 배치 오차 0.5ms였다.
- 후보 파일: Git 제외 `.local/demo-video/audience-2026-09-22T01-47-27-459Z/ai-go-demo-audience-candidate.mp4` (25,188,614 bytes, SHA256 `626b47e5f094066ca520830034943d7eb10f50e6aca5256cad416df3a53289fc`).
- 같은 폴더의 `timeline.json`, `dynamic-render-plan.json`, `audience-verification.json`, `verify_audience.py`와 화면 PNG에 근거를 보존했다.

## 최종 완료로 판정하지 않은 이유

발화 파형 기준 최장 무음이 35.044초였다. 클릭음을 발화로 계산하지 않는다. 화면 동작이 진행되더라도 사용자의 연속 설명 요구에는 부족해 후보로 보존하며 최종 제출본으로 제공하지 않았다.

추가 시각 검수에서는 3D 영상 재생 버튼으로 이동할 때 모달이 스크롤되어 초반 상자가 화면 위로 일부 벗어나는 점도 확인했다. 재생 3.33초부터 상자가 보이며 이후 구간 선택·기록 대조는 확인된다. 최종화 전에는 3D 재생 시작 시 영상 전체가 화면에 들어오도록 해당 녹화 구간을 보완해야 한다. 원본 검수 JSON의 파일 경로는 후보 이름 변경 전 이름이며 SHA와 내용은 위 후보에 해당한다.

CLOVA 프로젝트 `5161648`에 보충 해설 G~J 네 문단을 생성·저장했다. 센터 회신 등록, 배송 이관, 3D 구간·업무 비교, 마무리 설명이다. 다운로드 생성은 실행했지만 Codex 앱 저장 창을 현재 도구로 조작할 수 없어 사용자에게 Downloads 저장을 요청했다. 로컬에 보충 WAV가 도착했다고 가정하지 않는다.

저장 후에는 음원의 실제 길이와 발화를 확인하고 원본 타임라인을 보존한 채 G 116초 / H 89초 / I 234.5초 / J 287초 부근에 배치한다. 이 시각은 예상 배치이며 실제 음원과 겹침 검증 후 확정한다. 화면 재녹화나 가속 없이 재렌더한 뒤 음성 싱크·무음·자막을 다시 검수하고 Downloads에 최종 MP4를 제공한다. `--supplement` 렌더 옵션은 현재 미구현이다.
