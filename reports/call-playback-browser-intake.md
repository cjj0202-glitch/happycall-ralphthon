## 독립 적대검증

읽기 전용 `call_playback_adversarial`은 제품 결과물과 상태 계약을 받아 실제 CallReview TSX를 별도 메모리 harness로 실행했습니다. 초기10조건과 후속3조건이 통과했습니다. 두 선택을 렌더 전에 연속 호출한 뒤 source 변경, 교체 전 metadata/이벤트10종, 재생 중 native속도 변경, RAF구간, invalid native7값, played 시작/끝 공백, 가짜ended·seek, standalone/controlled 재시작, 새 재생 뒤 이전 ratechange를 포함합니다. React hooks·미디어·trusted/played는 합성이므로 실제 브라우저 관측과 분모를 분리합니다.

별도 변이4/4는 stale identity 제거 `0.75 !== 2`, 부모 callback 제거 `1.25 !== 2`, seek gate 제거 `1 !== 0`, pitch 보존 제거 `false !== true`로 검출했습니다. 최초10조건·모드4관측·변이4의 stdin 원문과 stdout은 같은 대화에 전달됐고, node stdin 실행 exit0으로 재현됐습니다. 후속3조건은 별도 실행이며 최초 원문 분모에 합치지 않습니다. 공개 재현 가능한 주 검사 명령과 고정 SHA는 [구현 보고](call-playback-preference.md)에 있습니다.

재사용 제약1건: `playbackRate` prop만 주거나 부모 callback이 새 값을 거부하면 UI1.25/native2로 달라질 수 있습니다. 현재 제품 소비처는 page.tsx 한 곳이며 Home setter와 값이 항상 같이 전달되어 실제 사용자 경로의 차단 결함으로 분류하지 않았습니다. 다른 소비처 추가 전에 해당 controlled 계약을 명시하거나 방어해야 합니다.
