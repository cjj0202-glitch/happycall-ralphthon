2026-09-21 메인7242c69의 `planning/media/production-quality.md` 및 DEC-022를 읽고 기존 N02 소유 범위에 연결했다. 한국어 통화 편집 A/B·대본/발음/화자/타이밍표·CallReview 연결 제안이 pc2 범위다. 이는 후속 제작 계획이며 새 편집 음원·청취 성공·최종 인수 결과가 아니다. 기존 #8의 추가 계약을 같은 이슈에서 이어받는다.

## 첫 후보의 수용 조건

1. 기존 원문·v2와 분리한 B 후보로 만들고 원본을 덮어쓰지 않는다. 상품·수량·단위·감정·추측·정정 의미를 바꾸지 않는다. 현재 UI의 시간표로 새 음원을 가장하지 않는다.
2. 음량/발음/쉼 중 한 조건만 바꿔 비교한다. 단어 재합성이 필요하면 실패 발화·후보 수·예상 호출을 메인의 기존 예산 원장에 연결한다. pc2는 자동 유료 합성/전사나 별도 원장을 만들지 않는다.
3. 편집 후보마다 원본/출력 SHA, 도구·버전·명령·변경 조건, 샘플/프레임·길이, 구간 매핑, RMS/peak/rail과 가능한 LUFS를 기록한다. 클리핑0·문장 끝 잘림 없음·약-18 LUFS를 각각 측정 가능한 범위로 구분한다.
4. 같은 장치·OS 음량·앱 음량·1배속에서 A/B 순서를 교차한다. 상품/수량/단위 정정과 두 화자 식별을 정답 노출 전 기록한다. 참여자/시도0인 현재 상태를 사람 청취 PASS로 바꾸지 않는다.
5. 메인이 채택한 후보만 Release/공용 manifest에 등록한다. 새 자산의 CallReview 구간·전체 종료 게이트와 최종 통합6회는 별도 검사이며 과거26 UI검사나 메인 구버전6회를 소급하지 않는다.

## 지금 필요한 자료와 경계

pc2에는 생성 발화별 원본 캐시/원 metadata와 FFmpeg 실행 환경이 없다. 기존 v2 전체 WAV와 pc1 보고의 구간표만 있다. 정밀한 발화 경계 편집이나 재조합 전에 승인된 캐시·타이밍 정본을 전달받거나, 메인이 어떤 전체 파일 편집을 채택할지 범위를 정해야 한다. 19:39 확인 당시 #8에는 N02-M2 후속 댓글이 아직 없었다. 이 자료 필요 사항은 현재 확인 상태 수정 회신과 함께 전달한다.

접근 허용 팝업의 출처는 아직 미확인이다. 현재는 자료 대조·설계만 수행하고 새 브라우저·검사 서버·렌더/설치 프로세스를 실행하지 않았다. 새 검증이 필요한 때에도 제어 서버는 이 PC 내부 주소에만 연결하며 보안 설정을 완화하지 않는다. 메인 소유 배포/API/미디어 등록과 기존 거부 조치의 우회는 이 후속에 포함하지 않는다.
