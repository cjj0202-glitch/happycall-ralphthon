# N04 기존 제품 UI 격리 재현 계획

검사 대상은 현재 `apps/web/app/page.tsx`와 `LogisticsView.tsx`입니다. 새 `TmsScene`은 공용 화면에 연결되지 않았으므로 이 검사는 그 컴포넌트의 통합·인수 증거가 아닙니다. AI Playwright의 기술 관측이며 실제 사람의 청취·검토·업무 효과를 대신하지 않습니다.

## 실행과 안전 경계

저장소 루트에서 `python tests/remote/pc4/flow-ui-run.py`를 실행합니다. 기존 8100/3100을 건드리지 않고 본 실행이 만든 API 18105/UI 13105만 사용합니다. Python은 기존 `.happycall-tools/python`, Node·Chromium은 준비된 로컬 실행 파일을 사용합니다. 외부 연결과 실제 분석기를 차단하고 `.env`를 읽지 않습니다. 실사용 접수·과금 원장은 변경하거나 초기화하지 않으며, 보존 여부의 전후 해시만 대조합니다.

각 검사 시작에 전용 테스트 엔드포인트가 새 임시 저장소를 선택합니다. 제품 상태 변경은 실제 HTTP를 호출하는 UI 버튼과 입력으로만 수행하며, 검증용 GET은 관측에만 씁니다. 새 임시 저장소 선택을 제품 기능 또는 UI 완료 단계로 세지 않습니다. 본 실행의 Next 자식 프로세스와 내부 Uvicorn만 정리합니다.

## 고정 분모

- CASE-0001 미도착·CASE-0002 오출고 각 3회, 총 6회입니다.
- 각 CASE 첫 회는 실제 WAV를 기본 1배속으로 처음부터 끝까지 재생합니다. 반복 2~3회는 기본 재생을 시작한 뒤 끝부분으로 명시적으로 탐색하고 실제 `ended`를 기다립니다. 가짜 이벤트 발송은 하지 않습니다.
- 종료 → 저장 결과 replay 분석 → WMS/TMS 원본·현재 사건 근거 연결 → 접수 편집·확인·이관 → 중간 회신·남은 조치의 종결 차단 → 조치 완료·최종 회신 → 경영주 조회·종결까지 UI로 진행합니다.
- 실패하면 API 직접 수정으로 메우지 않고 실제 완료한 단계, 실패·미실행 범위를 보존합니다.

별도 경계 검사는 신규 텍스트/다른 날의 자동 근거 연결 금지, 명시적 reference의 영상 미등록, MP4 404와 재시도, API 503과 거짓 저장 금지, API 단절 시 읽기 전용 예시/재연결, 실제 브라우저 offline/online 저장 복구입니다. 새 텍스트는 저장된 replay가 없으므로 실제 STT/GPT 정제 미실행을 명시합니다.

## 증거

각 실행은 `reports/pc4/ui-flow-<UTC>/results.json`, `harness.json`, 단계별 PNG를 생성합니다. HEAD·제품 소스 해시 전후·격리 저장소·응답 코드·완료 단계·호출 차단·실사용 상태 해시 보존을 기록합니다. 설치/실행 로그는 Git 제외 `.local/ui-flow-<UTC>/`에 보관합니다. 수치상 6/6이어도 이후 새 컴포넌트 통합이나 소스 변경의 검증은 별도입니다.

첫 탐색 실행의 두 실패는 요청사항 입력란을 정확한 label 문자열로 찾은 테스트 locator 문제였습니다. 실제 WAV 종료·replay·WMS/TMS 근거 연결까지 관측했고, 테스트 소유 파일의 locator만 수정해 같은 제품 소스로 재실행합니다. 이 실패를 제품 결함으로 분류하지 않습니다.
