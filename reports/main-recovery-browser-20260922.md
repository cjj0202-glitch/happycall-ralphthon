## 범위와 환경

## 발견한 UI 문제

상담 초안을 유지한 채 WMS/TMS에서 근거를 저장하면 서버 revision은 증가하지만 메모리 초안의 formRevision은 이전 값으로 남습니다. 두 사례 모두 상담 복귀 시 자기 저장에도 충돌 경고가 표시됐습니다. 최신 내용 대조 → 내 초안 유지 → 재확인으로 데이터 손실 없이 진행했습니다. 위 2회 완주는 이 복구 절차를 포함한 결과입니다. 수정과 같은 경로 재검은 [근거 자기 저장 검토](evidence-self-conflict-review.md)에 따로 기록합니다.

06:56 이후 수정 UI를 reload하고 별도 합성 접수 `INT-E83B2583`에서 미저장 요청·출고 부서·확인 체크를 만든 뒤 WMS E-W3을 연결했습니다. 복귀 화면에서 충돌 경고 없이 요청·부서·근거가 보존됐고 확인 체크만 해제되어 이관이 잠겼습니다. 다시 확인한 뒤 실제 센터 이관을 저장했고, 센터 화면에 정확한 미저장 요청 문구와 E-W3이 표시됐습니다. 새 텍스트 사례의 재검이며 분석 직후의 누락 메타데이터 경계는 별도 실제 JSX/store 검사에 포함됩니다.

첫 재검용 접수 `INT-5DA7C39C`는 기존 사례 선택 뒤 제목을 바꿨기 때문에 연결이 해제됐고 WMS 영상·근거가 차단됐습니다. 정상적인 사건 관계 보호이며 삭제하지 않고 보존했습니다. DOM 입력값 읽기 도구가 2회 시간 초과했으나 최신 DOM snapshot과 실제 이관 결과로 위 값을 확인했습니다. 시간 초과를 기능 통과로 세지 않았습니다.
