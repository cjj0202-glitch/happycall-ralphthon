## 해줘야 할 일

- 실제 자기 세션 원본의 시작 시 길이까지만 별도 로컬 snapshot으로 복사합니다. 마지막 행이 미완성이면 완료 로그로 만들지 않고 누락 tail bytes를 기록하세요. 원본·기존 snapshot을 덮어쓰지 않습니다.
- 선택 이유, snapshot bytes/SHA256/JSON 객체 행수/불량 행/빈 행, 첫·끝 사건 시각, 공식 제출 1GiB/파일 및 HowLong256MiB/파일 대조를 기록합니다. 한 파일의 크기를 팀 전체 통과로 확장하지 않습니다.
- 실제 작업 호출과 결과의 존재, 완료/미완료 턴을 구조로 구분합니다. Goal이 자기 로그에 없으면 없다고 적고 메인의 실제 Goal을 복제/합성하지 않습니다. 토큰 누적값 단순합산·예상 점수·시간 늘리기 금지입니다.
- 키·회사자료·미디어/opaque 내용 점검은 완료가 아니면 미검토로 남깁니다. 발견값·원문·주변문맥은 stdout·보고서·이슈에 출력하지 않습니다. 이 배정에서 정제본 생성이나 외부 HowLong 입력·업로드·공식 제출을 하지 않습니다.

## 실행·검증 기준

기존 `scripts/log_inventory.py`의 `inspect`는 명시 경로의 메타데이터만 반환합니다. CLI는 기존 `.local/log-manifest.json`을 덮어쓸 수 있으므로 그대로 재실행하지 말고, 함수 반환을 새 감사 폴더에 보존하거나 같은 조건의 streaming 검사로 실행하세요. 쉘 명령에 로그 본문을 인라인하거나 모든 환경변수를 출력하지 마세요.

기대값: 원본 고정 접두사와 snapshot SHA 일치, JSON 객체 분모>0, 원본/기존사본 불변, Git ignore 확인, 외부 전송0. 합성 정상1·불량1 대조로 검사기가 실제 입력을 보고 불량을 잡는지도 확인합니다. snapshot의 진행 중 마지막 턴은 성공 완료로 세지 않습니다. raw 값 없이 명령·exit·분모를 보고하세요.
