BMAD 네 관점은 원형 음원 보존이라는 사용자 결과, 미확인/파생값을 드러내는 검토 흐름, 아래 데이터 계약, 실행 가능한 반례로 짧게 연결합니다. 첫 Bolt는 인공 2사례×10턴 정상 묶음 하나와 틀린 gap 하나를 비교하여 실제 차단을 확인하는 것입니다. 이후 구현→실행→발견 결함→수정→동일 조건 재검으로 진행합니다.

### 입력·타임라인 계약

- 고정 대본 SHA를 먼저 대조합니다. `caseId`, turn ID, 배열 순서, `speaker`, 화면용 `text`, 발음용 `spokenText`를 각각 고정 대본과 대조합니다. 2사례·각 10턴·전체 20턴이 정확히 있어야 합니다. 재정렬·오타 교정·문장 합치기로 잘못된 입력을 정상화하지 않습니다.
- 편집기에 입력한 본문은 `spokenText`와 비교하고, fixture 후보의 표시 본문은 `text`를 보존합니다. 숫자 표기가 다른 5턴을 혼동하지 않습니다. 특히 F5-W03은 상담원의 잘못된 “휴지 한 개” 질문이며, F5-W04는 경영주의 “한 개가 아니라 한 박스” 정정입니다. 화자나 문맥상 오류를 자동 수정하지 않습니다.
- pc1이 독립적으로 고정해 전달한 원본 WAV의 case 매핑·bytes·SHA256, 관측 원문/파일 해시, 대본 SHA, 공식 편집기 관측 출처·시각을 입력 계약에 둡니다. 후보 자체가 자기 기대 SHA를 정하지 않습니다. 파일명이나 길이만으로 사례를 추정하지 않습니다.
- 모든 턴의 `startSeconds`와 중간 1~9턴의 `officialGapAfterSeconds`는 공식 편집기에서 실제 관측한 유한한 비음수 수치여야 합니다. bool/문자열/NaN/Infinity/null을 수치로 받아들이지 않습니다. 필요한 중간 gap 미확인은 0이나 제안 pause로 채우지 않고 `unresolved`로 기록하여 후보 승인을 거절합니다. 마지막 10턴은 end가 decoded 파일 끝으로 정해져 gap에 의존하지 않습니다. 마지막 gap 조절기가 UI에 표시되지 않으면 `gapObservationStatus=not_displayed`, `officialGapAfterSeconds=null`을 허용하고 숫자0으로 추정하지 않습니다. 이 마지막 예외가 중간 턴에 적용되면 거절합니다.
- 중간 턴 i의 `endSeconds = startSeconds[i+1] - officialGapAfterSeconds[i]`입니다. 마지막 턴의 `endSeconds = decodedFrameCount / sampleRate`입니다. 마지막 공식 쉼 값은 원관측으로 보존하되 마지막 end에서 다시 빼지 않습니다. 두 경우 모두 end는 파생값이고, 음성 발화의 실제 끝점을 샘플 단위로 측정했다는 뜻이 아닙니다.
- `0 <= start < end <= decodedDuration`, 시작 시각의 엄격한 증가, 중간 `end <= nextStart`를 검사합니다. gap 때문에 음수/역전/0길이가 생기거나 decoded 끝을 넘으면 거절합니다. 무음 검출·강제 정렬·일괄 이동·클램핑으로 통과시키지 않습니다.
- 공식 UI의 0.01초 표시 분해능은 기록하되 ±0.01초의 실제 정확도를 보장한다고 쓰지 않습니다. 관측 start/gap, 그 출처, end 계산식과 계산 근거를 결과에 따로 남깁니다. 추정 오차를 음원 편집으로 없애지 않습니다.
- 전체 WAV는 공식 파일 원형을 유지합니다. 재인코딩·정규화·리샘플링·채널 변경·클립 자르기/재연결·무음 추가/삭제·속도 변경을 하지 않습니다. 후보에 WAV 사본을 두면 원본과 bytes/SHA256이 2/2 같아야 하며 입력의 검사 전후 SHA도 같아야 합니다.
- 실제 파일이 RIFF/WAVE PCM16인지 먼저 확인합니다. 지원하는 경우 전체 데이터의 실제 프레임 수·sample rate·채널·sample width·decoded 끝을 계측하며, 잘린 데이터·손상 헤더·프레임 단위 불일치를 거절합니다. PCM16 외 형식이면 현재 측정기의 지원/미지원과 관측 가능한 헤더 사실만 보고합니다. 설치나 자동 변환으로 맞추지 않고 미지원 계측을 PASS로 바꾸지 않습니다.
- 출력에는 인공/공식 입력 출처, `candidate` 상태, 미확인 필드, 원본·대본·관측 해시, 모든 판정 근거를 남깁니다. 메타데이터 정합은 실제 음성의 화자·문장 일치나 청취/STT/UI 품질을 입증하지 않습니다. 실제 음원이 없으면 공식 음원 검증은 `NOT_RUN` 0/2, 실제 타임라인 대조는 `NOT_RUN` 0/20으로 유지합니다.

각 항목에 실제 실행 분모·PASS/FAIL/SKIP/NOT_RUN, 명령·출력, 환경·시각을 남깁니다. 실패와 OS 권한 제한을 지우지 않습니다.

## 6. 중단 조건 + 인계

소유 충돌, 원천/키 접근 요구, 정책·권한 거절, 지원하지 않는 공식 WAV, 중간 턴의 실제 gap 미확인, 원본 해시 차이, 입력의 검사 중 변경은 해당 경로를 중단하고 증거를 반환합니다. 다른 도구·계정·PC로 권한 거절을 우회하지 않습니다. 공식 입력이 없다는 이유로 인공 자료를 공식 원음으로 표시하지 않습니다. 독립 가능한 인공 단위검사는 계속할 수 있습니다.
