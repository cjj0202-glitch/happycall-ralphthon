## HowLong과 공식 제출의 확인 한계

[보존된 공식 HowLong 본문](../../docs/official/2026-09-21/howlong.dom.txt)은 파일 선택/JSON 붙여넣기로 브라우저 안에서 계산하며 서버/API로 보내지 않는다고 안내합니다. 100파일, 256MiB/파일, 512MiB/전체 제한과 완료 턴만 최장 실행 포함, 분석이 제출·점수가 아니라는 안내도 있습니다. 이는 저장된 공식 설명이지 이번 감사에서 네트워크 전송 부재를 검증한 결과가 아닙니다.

21시 새 확인에서는 [공식 HowLong](https://52g-hackathon.ralphthon.org/howlong), 가이드·심사 페이지가 web 도구에서 접근 실패했고, 공개 HowLong 페이지를 읽는 Python GET은 HTTP 403이었습니다. 응답을 우회하거나 로그를 보내지 않았습니다. 공식 JavaScript 실행 코드·로컬 CLI·JSON 내보내기 계약을 확보하지 못했으므로 자체 계산 결과를 HowLong 공식 결과로 대신하지 않았습니다.

현재까지 확인된 제출 규격은 [docs09](../../docs/09_공식규정_전수대조.md)의 보존 자료 기준입니다. 주요 JSONL 한 개, 추가 로그는 선택 ZIP 한 개, 파일당 1GiB·팀 합계 10GiB, 발표 최대 5페이지·90MiB, 공식 최종 마감 2026-09-22 12:00 KST입니다. 로그인 뒤 제출 폼·대표 권한·실제 저장/제출·정제본 수용 여부는 이번 감사에서 확인하지 않았습니다.
