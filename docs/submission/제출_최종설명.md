## 짧은 버전 (권장)

AI-GO 무엇이든 물어보살은 점포에서 걸려온 해피콜 한 건을 상담원·센터·경영주가 같은 사건으로 이어받는 업무 콘솔입니다.

전화 녹음이나 웹 문의가 들어오면 AI가 통화를 전사하고 점포·상품·수량·요청사항으로 접수서를 정리합니다. 상담원은 원문과 대조해 확인한 뒤 담당 부서로 넘기고, 센터 담당자는 센터 작업 기록과 배송 기록, 합성 3D 소터 장면을 함께 보며 답변을 작성합니다. 등록한 답변만 경영주 화면에 나타납니다.

동작하는 범위: 전화·웹 접수부터 AI 정리, 물류 기록 대조와 근거 연결, 부서 이관, 센터 중간·최종 회신, 경영주 수신까지 한 흐름이 공개 링크에서 실제로 동작합니다. 전 흐름 자동 검증 33개 항목과 서버 계약 테스트 181개를 통과했고, 1440·921·390 폭에서 가로 넘침 없이 렌더됩니다.

아직 아닌 범위: 모든 통화·점포·물류 기록은 시연용 합성 데이터이며 실제 고객 통화나 실제 CCTV가 아닙니다. Teams·카카오 알림은 화면에 연결 안 됨으로 표시합니다. 기록을 확인했다는 것이 실제 도착이나 책임을 확정하지는 않으며, 화면도 그렇게 말하지 않습니다. 사람 사용성 검수와 운영 인증은 별도 과제로 남습니다.
