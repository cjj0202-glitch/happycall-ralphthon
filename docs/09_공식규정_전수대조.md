자동 분석의 근거와 제출 내용을 심사위원이 확인해 점수를 확정합니다. **점수 구간별 공식 산식·토큰 수에 비례한 가점표는 공개 페이지에서 확인하지 못했습니다.** 이 배점만으로 자체 만점을 보장하거나 불필요한 실행/토큰을 늘리지 않습니다. 업무 결과와 검증 근거의 질을 높이는 것이 우리의 준비 방향입니다.

## 5. 선발·결선·투표

- 전 팀 1차 평가 → 상위 **15팀** 근거/데모 확인 → 결선 **4팀**.
- 결선 총점 = **검증된 1차 원점수 × 0.5 + 발표·질의응답 25 + 참가자 투표 25**.
- 발표 **5분**, 질의응답 **3분**. 화려한 자료·말솜씨에 별도 점수가 붙는다고 안내하지 않습니다.
- 투표는 참가자 한 명이 **다른 한 팀**을 선택하고 확정 후 변경할 수 없습니다. 기준은 업무에서 실제로 사용하고 싶은 결과물입니다.
- 투표 점수 = 팀 득표수 ÷ 최다 득표수 × 25. 최다 득표가 0인 특수 상황의 처리식은 공개 안내에 없으므로 임의 계산하지 않습니다.
- 최종 1·2위는 심사위원이 확정하며 동점도 근거를 함께 확인해 결정합니다.
- 검증된 상위 **10팀**은 팀당 OpenAI API Credit **1,000달러** 안내. 별도 [우수팀 이벤트 안내](https://52g.oopy.io/63cf800b-d1c1-82a9-a39f-81254102d286)는 우수팀 전원에게 인당 Mac mini를 안내합니다. 동일한 수상 범위라고 임의로 합치지 않습니다.

## 6. HowLong의 정확한 범위

파일 선택 또는 JSON 붙여넣기. 웹 안내상 브라우저 안에서 계산하고 서버/API로 업로드하지 않으며, 대화 내용을 결과에 표시하거나 내보내지 않습니다. 별도 저장소/분석 DB를 만들지 않는다고 안내합니다. 이는 운영자의 설명을 기록한 것이며 네트워크 트래픽 전체를 보안 감사했다는 뜻은 아닙니다.

- 실행 수는 기록된 **턴 수**이며 에이전트 수가 아닙니다.
- 시작·완료가 확인된 실행만 최장 실행 계산에 포함됩니다.
- 같은 파일은 한 번 계산하지만 내용이 다른 포크·리플레이에는 겹침이 있을 수 있습니다.
- 가격 근거가 없어서 비용은 계산하지 않습니다.
- 분석 결과는 **제출 확인이나 심사 점수가 아닙니다**.
- 로컬 분석 도구 한도: **100개**, 파일당 **256MiB**, 합계 **512MiB**. ZIP은 풀어서 선택합니다. 공식 제출의 1GiB/10GiB와 다릅니다.
- 기록판의 '예시'는 우리 실적이 아닙니다. 캡처 `howlong-example.png`도 예시를 확인한 화면입니다.

## 7. Goal 작성·운영 반영

공식 Handoff는 목표, 맥락·자료, 결과물, 완료 기준, 허용 범위, 진행 방식, 결과 보고로 구성됩니다. 목표를 상세하게 주고 구현→실행→검증→수정까지 이어가며, 사소한 선택은 판단하되 중요한 결정이 필요한 때만 질문하도록 합니다.

우리 구현 초안은 [GOAL.md](../GOAL.md), 사용/로그 보존 절차는 [10](10_Goal과_로그_운영.md)입니다. TODO는 검증 가능한 덩어리를 위한 내부 관리 수단입니다. 매번 사람이 한 줄 명령을 다시 주어야만 움직이는 방식으로 Goal을 좁히지 않습니다. pc1은 승인된 범위에서 다음 준비된 작업을 자율 배정하고, 워커는 그 덩어리의 구현·실행·수정을 끝까지 수행합니다.

모델/강도: 가이드는 기본 강도부터 시작하고 필요할 때 높이도록 안내합니다. Max는 한 작업의 추론 시간, Ultra는 독립 작업의 병렬 처리 설명입니다. 가용성은 실제 계정 선택기에서 확인합니다. 높은 강도 자체가 공식 가점이라는 근거는 없습니다. 현재 pc1 설정을 임의 변경하지 않습니다.
