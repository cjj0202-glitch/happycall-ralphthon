# 로컬 시연 실행 안내

**공유 미디어:** 인증된 GitHub CLI로 `python scripts/fetch_demo_media.py`를 실행하면 고정 Release의 WAV2개·MP4를 받아 manifest 해시/크기를 대조합니다. `--verify-only`는 다운로드 없이 확인합니다. Release 발행 여부와 근거는 reports/media-share.md를 보며, 누락 시 유료 재생성을 자동 실행하지 않습니다.

Windows의 이 저장소에서 실행합니다. 웹은 <http://127.0.0.1:3100>, API는 <http://127.0.0.1:8100/api/health>입니다. DEC-018에 따라 9/22 09시 배포까지 재확인 없이 진행합니다. 호스팅·인증의 최신 사실은 DEC-019와 docs/12를 따르며, 로그인 재시도를 최종 배포 대상 확정으로 해석하지 않습니다.

## 설치와 시작

PowerShell에서 다음 명령을 실행합니다. Python 3.12 환경은 `uv sync`가 구성합니다. Node.js와 npm이 필요합니다.

```powershell
Set-Location 'C:/00.프로젝트/happycall-ralphthon'
uv sync
Set-Location apps/web
npm.cmd ci
Set-Location ../..
python scripts/start_demo.py
```

이미 설치했다면 마지막 명령만 실행합니다. 런처는 `.venv/Scripts/python.exe scripts/run_demo_server.py`와 `apps/web`의 `npm run dev`를 새 창 없이 실행합니다. npm은 `node.exe`로 `npm-cli.js`를 호출하므로 PowerShell 실행 정책을 변경할 필요가 없습니다. Python 가상환경 활성화도 필요하지 않습니다.

`Demo ready` 출력 후 웹 주소를 엽니다. 시작 후 준비 확인은 최대 약 60초이며 API JSON의 `status=ok`, `synthetic=true`, `runtime=local-demo`와 웹 HTML 응답을 확인합니다. `liveReady=false`여도 저장 결과 시연은 가능합니다. `liveReady=true`는 실제 AI 호출 성공을 보장하지 않습니다. 런처는 키 파일을 읽거나 API 과금 요청을 보내지 않습니다.

## 종료와 충돌 처리

```powershell
Set-Location 'C:/00.프로젝트/happycall-ralphthon'
python scripts/stop_demo.py
```

PID·정확한 명령줄·프로세스 생성 시각이 기록과 일치하는 런처 소유 프로세스와 그 자식만 종료합니다. 다른 세션이 실행한 서버는 종료하지 않습니다. 같은 런처를 중복 시작하면 준비 상태만 확인합니다. 관리 중인 서버가 비정상이면 로그를 확인하고 종료 후 시작합니다.

8100/3100 포트를 다른 서버가 사용하면 시작을 거절합니다. 해당 서버를 실행한 세션에 상태를 확인하십시오. 포트 번호만 보고 `taskkill`하거나 전체 Python/Node 프로세스를 종료하지 않습니다. PID 파일을 지우면 소유권 증거가 없어지므로 실행 중 임의 삭제하지 않습니다.

상태와 로그는 Git 제외 경로 `.local/demo-launcher/`의 `processes.json`, `backend.log`, `web.log`에 저장됩니다. 설치 누락 안내가 나오면 위의 `uv sync` 또는 `npm.cmd ci`를 실행합니다. 준비 시간 초과나 자식 프로세스 종료 시 이번 런처가 만든 프로세스를 정리하고 실패를 반환합니다. 종료 확인에 실패하면 상태 파일을 보존하므로 오류를 확인하고 종료를 다시 실행합니다.

## 시연 순서

아래는 코드에 구현된 버튼과 흐름을 기준으로 한 안내이며, 실제 사람이 완료한 테스트 결과가 아닙니다. 기본 모드는 **저장 결과 재생 · API 호출 없음**입니다.

1. **상담 작업대 → CASE-0001 아침 배송 미도착 확인**에서 합성 음성을 확인합니다. 기본 모드의 **저장된 분석 결과 재생**은 과금 없는 재생입니다. 실제 AI를 시연하려면 **실제 AI 분석 · API 사용**을 선택하고 음성을 끝까지 재생한 뒤 **AI 전사·정제 실행**을 명시적으로 클릭합니다. 이 클릭은 외부 AI API 호출과 실제 비용을 발생시킬 수 있습니다. 키는 로컬 `.env.demo.local`에서 별도 관리하며 화면·로그·문서에 값을 붙이지 않습니다.
2. **TMS 배송 확인 → 설명 재생 → 점포 선택 → 원본 행 보기 → 이 근거 연결** 순으로 확인합니다. 규정 도착, 배송완료, 모바일 진입·이탈을 구분합니다. 도착 실적이 없다는 사실을 실제 미도착 확정으로 바꾸지 않습니다. 지도와 트럭 애니메이션은 설명용 가상 동선이며 실제 GPS·현재 위치 증거가 아닙니다.
3. **CASE-0002 주문 상품과 다른 상품 입고**에서 최초 접수 `1 EA`와 경영주 정정 `1 BOX`의 단위 충돌을 보여줍니다. 저장 AI 제안의 `1 BOX`를 원문과 대조합니다. 주문 `18 EA`와 수령 `1 BOX`를 단순 차감하지 않습니다.
4. 별도 **WMS 작업 확인** 화면에서 주문·점포 수령·출고 스캔을 확인하고 **기록 확인**과 **원인 미확인**을 구분합니다. WMS 작업 애니메이션과 TMS 운송 지도는 서로 다른 설명 화면입니다. `/demo/sorter-demo.mp4`는 **합성 영상 · 실 CCTV 아님**이며 오출 위치나 귀책을 입증하지 않습니다.
5. 상담 작업대에서 접수 필드 또는 전달 부서를 실제로 한 번 편집한 뒤 **점포·상품·전달 부서를 원문과 대조하고, 접수 정보를 편집·확인했습니다.**를 체크하고 **확인 후 센터 전달**을 누릅니다.
6. **센터 회신 → 초안을 편집창에 가져오기** 후 문장을 검토·편집하고 **중간 회신 등록**을 누릅니다. 남은 조치를 확인하여 실제 시연 과업에 맞게 **완료** 처리한 다음 **최종 회신·처리 완료**로 마칩니다. **경영주 수신 화면 확인**에서 회신을 확인합니다. UI의 시연 역할 전환은 실제 운영 권한 검증을 대신하지 않습니다.
7. **경영주 접수**에서 유형·점포코드·문의 제목·상세 내용을 직접 입력하고 **문의 접수하기 → 시연: 상담 작업대로 이동**으로 텍스트 직접 제출도 보여줍니다.

## 데이터와 반복 시연의 한계

소스 fixture는 전달된 과거 답변 33개 패턴, WMS 30개·TMS 36개 기록 구조를 참고한 독립 합성 자료입니다. 운영 데이터와 실 CCTV를 연동한 결과라고 설명하지 않습니다. 이 수치는 시연 입력의 구성 설명이며 정확도·고객 관찰 표본 수가 아닙니다.

처리 상태는 `.local/cases-store.json`에 남습니다. 서버 재시작은 케이스 초기화가 아닙니다. 이미 센터에 전달했거나 진행·종결한 케이스는 분석·상담 편집이 잠길 수 있습니다. 반복 시연 전에 현재 상태를 확인하고, 초기화가 필요하면 다른 작업자가 사용 중인지 확인한 뒤 담당 메인과 별도로 진행합니다. 런처는 케이스 데이터와 API 예산을 초기화하지 않습니다.

AI Playwright 자동 검증과 실제 사람의 조작 관찰을 구분합니다. 자동 검증 통과를 사람 사용성 테스트·센터 검수·실제 업무 성과로 기록하지 않습니다. 음성·영상 브라우저 재생, 실과금 전사·정제, 다른 PC 재현은 실제 수행 증거가 있을 때만 완료로 기록합니다.

## 이번 작성 시 검증 범위

2026-09-21 pc1(CJJ)에서 두 Python 파일의 문법 검사를 실행했습니다. 런처 시작 검증에서는 다른 세션이 선점한 8100/3100 포트를 감지하여 `Port 8100 or 3100 is occupied by an unmanaged service`로 종료 코드 1을 반환했습니다. 외부 서버에 대한 종료나 중복 기동은 실행하지 않았습니다. 따라서 이 기록은 충돌 방어의 실측이며, 런처의 실제 신규 기동·종료 성공은 미검증입니다. 정확한 식별자 일치/불일치, PID 재사용, 명령줄 변경, 자식 추적과 외부 프로세스 제외, 중복 시작 시 Popen 미호출, 정상·불완전·비합성 health JSON 판별은 모의 입력 검증을 통과했습니다. 이 안내 작성 중 실제 AI 호출과 사람 시연은 수행하지 않았습니다.
