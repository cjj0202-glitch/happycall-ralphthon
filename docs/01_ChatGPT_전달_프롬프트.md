먼저 `python channel/whoami.py`로 실제 슬롯을 확인합니다. 미등록이면 hostname·GitHub 계정을 메인에게 전달하고, 중앙표를 직접 고치지 않습니다. 사전 준비용 읽기 전용 점검은 미등록 상태에서도 가능합니다.

작업 ID와 끝난 조건은 `python ops/tasks.py show ID`로 읽습니다. 워커는 기대값과 실제 결과를 비교하고 커밋·증거를 회신합니다. pc1이 REVIEW → 검증 → accept 후 TODO를 체크하고 이슈를 닫습니다. 한 PC의 진행/검증 대기는 하나입니다.

최초 세션은 자기 미처리 편지를 한 번 확인합니다. 이후 `watch --once`는 변경 알림입니다. 조용해도 기존 미처리 업무가 없다는 뜻이 아닙니다. 별도 터미널 감시기는 멈춘 세션을 깨우지 않습니다.

역할은 docs/05의 제안과 각 PC 준비 결과를 보고 메인이 pcs.json에 등록합니다. 실제 권한/인증/배포 여부는 각 PC에서 확인하며, 계정 비밀번호·API 키를 공유하지 않습니다.
