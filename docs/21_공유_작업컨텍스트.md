**전달할 통합 프롬프트:** [PROMPT_team.md](../PROMPT_team.md). 제품·방법론·공식 배점·실행 증거·4PC 배정을 함께 읽습니다. 결정 정본은 DEC-015까지 반영됐습니다.

## 지금 만들고 있는 결과

경영주가 상담원과 통화하거나 사이트에 글을 제출합니다. 통화는 AI가 미리 만든 한국어 두 화자 음성을 재생하고 **종료 후 실제 API로 전사·정제**합니다. 정제 요약·접수서·수량/단위 불일치·추가 질문·부서 추천을 사람이 검토합니다. 미도착/오출고 두 유형을 유지합니다.

해피콜에서 별도 WMS·TMS 화면으로 같은 케이스를 열어 관련 기록을 확인합니다. WMS 피킹·분류·슈트·합성 소터 이동 애니메이션, TMS 방문순서 지도·트럭 연출·계획/완료/진출입 시각을 표시합니다. 영상은 합성 공정 설명용이고 실 CCTV나 오출 원인 증거가 아닙니다.

상담원이 점포·문의 대상·담당 부서를 확인해 이관합니다. 수량 미확인은 이관을 무조건 막지 않습니다. 센터 담당자가 최종 회신하며 경영주 화면에서 등록 답변을 확인합니다. 남은 조치가 있으면 처리 중, 조치가 끝나고 회신이 있으면 종결합니다.

결정 정본: [planning/decisions.md](../planning/decisions.md) DEC-001~014. 사용자 결정과 AI 제안, 미확인을 구분합니다. 이 문서는 네 사람의 동의를 생성하지 않습니다.

## 파일 충돌을 막는 배정 규칙

메인(pc1)만 작업을 배정합니다. 다른 PC는 이 문서를 읽었다는 이유만으로 이미 작업 중인 경로를 수정하지 않습니다. 메인 이슈에 **작업 ID·기준 커밋·소유 파일·읽기 전용 의존 파일·수용 기준**이 있어야 구현합니다.

로컬 최초 구현 분담은 [착수 기록](../reports/kickoff-expedited.md)에 있습니다. 같은 PC의 대기 세션은 pc2~4가 아닙니다. 실제 PC의 계정·hostname·역할·편지함은 `channel/pcs.json`이 정본입니다. 미등록 PC는 [docs19](19_4PC_편지함_감시_빠른시작.md)에 따라 준비 보고만 합니다.

원격 PC가 준비되면 메인은 통합 결과를 보고 한 건씩 배정합니다. 우선 후보는 **① 접수·센터 UI 재현/개선 ② WMS·TMS 데이터·화면 대조 ③ 독립 시연 검증**이며 아직 사람·계정별 배정 완료가 아닙니다. 이미 수정 중인 파일은 기존 담당자의 완료/인계 후 소유를 이전합니다.

## 질문·결과 전달 형식

작업 이슈 한 곳에 이어서 기록합니다. 채팅에서만 합의한 내용은 메인이 결정 문서에 반영해 커밋을 알려줍니다. 워커끼리 다른 워커에게 변경 지시를 내리지 않습니다.

```text
[질문]
작업 ID / 기준 커밋 / 현재 내 HEAD:
막힌 지점과 재현 명령:
관측한 출력 / 기대값:
영향 받는 파일:
제안 A / B 및 추천 이유:
답을 기다리지 않고 진행 가능한 범위:

[완료 또는 검토 요청]
작업 ID / 기준 커밋 / 결과 커밋:
수정 파일:
검증 명령 / 기대값 / 실제 결과:
스크린샷·증거 경로:
남은 한계 / 과금 호출 유무:
메인에게 요청하는 인수 또는 수정:
```

메인은 변경 범위를 대조하고 빌드·API·Playwright로 재현합니다. 수정은 원 담당 또는 메인이 **소유권을 명시적으로 이전받아** 수행합니다. 검증 전 완료 체크·작업 이슈 종결을 하지 않습니다. 변경이 겹치면 덮어쓰기/reset/stash하지 않고 충돌 경로를 보고합니다.

## 전달하지 않는 것과 검증 상태

- `.env.demo.local` 키, `.local` 사용자 작업 상태, 원본 세션 JSONL은 GitHub에 올리지 않습니다.
- WAV/MP4는 Git에 포함하지 않습니다. 생성기를 실행하거나 별도 공유한 Release 자산을 사용합니다. 다운로드 경로·해시가 전달되지 않았으면 미디어가 공유됐다고 가정하지 않습니다.
- API는 제품 시연 전용입니다. 자동검사는 replay/tempstore이며 실제 API 호출로 비용을 만들지 않습니다. 합성 음성 준비와 명시적 live 시연만 허용합니다. [API 정책](18_OpenAI_데모_API_연결.md) 유지.
- 현재 인수는 **AI Playwright**입니다. 실제 사람 사용성 관찰을 대신 성공했다고 주장하지 않습니다.
- 기존 TODO 45개와 이번 빠른 구현의 진척은 같은 지표가 아닙니다. `ops/tasks.py`에 증거로 인수하지 않은 항목을 임의 완료 처리하지 않습니다.
- Vercel/AWS 배포, 실제 WMS/TMS 연결, 실제 물류 조치, 공식 Goal 실행·최종 제출은 별도로 검증해야 합니다.

최신 확인은 `git rev-parse HEAD`와 메인이 전달한 결과 커밋을 대조하고, [reports/e2e](../reports/e2e)·백엔드 테스트·실행 보고를 읽습니다. 이전 세션의 '정상' 문구만 믿지 말고 해당 PC에서 실행한 사실을 회신합니다.
