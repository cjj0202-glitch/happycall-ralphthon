## 📋 복사 시작

```
해커톤 준비입니다. 노트북에서 15분이면 됩니다. 순서대로만 해주세요.

■ 1. 초대 수락 (이미 보냈습니다)

  https://github.com/notifications  또는 메일에서 수락해주세요.
  저장소 2개입니다 — happycall-ralphthon, hackathon-ai-kit

■ 2. 도구 (없는 것만)

  winget install --id Git.Git --exact
  winget install --id GitHub.cli --exact
  winget install --id Python.Python.3.12 --exact
  winget install --id OpenJS.NodeJS.LTS --exact

  설치 후 PowerShell 을 «새로 여세요». 안 그러면 명령을 못 찾습니다.

■ 3. 로그인

  gh auth login
  gh auth status

■ 4. 받기 — 두 폴더가 «나란히» 생기게, 같은 상위 폴더에서 실행

  gh repo clone cjj0202-glitch/happycall-ralphthon
  gh repo clone cjj0202-glitch/hackathon-ai-kit
  cd happycall-ralphthon

■ 5. 점검

  python scripts/preflight.py

  PASS/FAIL 표가 나옵니다.
  slot_registered 가 PENDING 인 것은 «정상»입니다 — 아직 제가 등록을 안 했습니다.
  다른 줄이 FAIL 이면 그 줄만 저한테 보내주세요.

■ 6. 저한테 보낼 것 — 두 줄

  python channel/whoami.py --hostname
  gh api user --jq .login

  이 두 줄의 결과를 보내주세요. 제가 등록하고 알려드립니다.

  🚨 파일을 직접 고치지 마세요. 남의 편지함을 읽게 되는 사고가 납니다.

■ 7. 제 연락 받고

  git pull
  python scripts/preflight.py      ← slot_registered 가 PASS 로 바뀌어야 합니다

  그 다음 제가 «작업 하나»와 시작 프롬프트를 보냅니다.

──────────────────────────────
막히면 바로 물어보세요. 혼자 30분 넘게 붙잡지 마세요.
```

## 메인이 보내기 전 확인

| 확인 | 왜 |
|---|---|
| 초대를 **먼저** 보냈는가 (`gh api repos/.../invitations` 에 뜨는가) | 수락이 안 되면 4번 clone 부터 막힌다 |
| 수락됐는지 확인했는가 (`collaborators` 에 뜨는가) | 초대만으로는 권한이 없다 |
| hostname 을 받아 `pcs.json` 에 넣고 **push 했는가** | push 안 하면 상대가 `git pull` 해도 여전히 미등록이다 |
| 역할·작업 ID 를 정했는가 | 「뭐 하면 되냐」가 되돌아온다 |

## 🚨 현장에서 가장 많이 걸리는 것

| 증상 | 원인 | 한 줄 |
|---|---|---|
| `gh: command not found` | 설치 후 터미널을 안 새로 열었다 | PowerShell 새로 열기 |
| clone 이 404 | 초대를 아직 수락 안 했다 | `gh api repos/cjj0202-glitch/happycall-ralphthon --jq .full_name` |
| `codex --version` 이 「Missing optional dependency」 | 와이파이가 끊겨 네이티브 패키지가 반쪽만 깔렸다 | `npm uninstall -g @openai/codex` 후 재설치 |
| `whoami` 가 계속 미등록 | 메인이 `pcs.json` 을 push 안 했다 | 메인이 push → 상대가 `git pull` |
