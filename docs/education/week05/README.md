# FDE 5주차 — 사용자 제공 원본 캡처

OneDrive에서 2026-09-21 수신한 통짜 1장과 분할 10장입니다. 두 벌은 같은 강의 화면을 담는 것으로 제공되었습니다. PNG 11개를 실제 읽어 저장했고 원본/저장소 사본 SHA256 11/11을 대조했습니다. 분할 10개 폭과 높이 합계가 통짜와 일치합니다. 원격 Administrator PC의 MD5 값은 제공되지 않아 그 PC와의 해시 일치까지 주장하지 않습니다.

분할 p01~p10은 에이전트 두 명이 담당 구간을 나눠 직접 열람했습니다. 통짜는 크기·파일 무결성 확인용입니다. 강의 웹 원문은 이번 접속에서 403이었으므로 이는 현재 웹의 재캡처가 아니라 사용자가 제공한 캡처입니다. 교육 과제 명령은 현재 해커톤의 실행 명령이 아닙니다.
