# 기술스택 결정카드 — OneFlow

2026-09-21 설계 기준선. **제품은 T1 신규 독립 앱**, 현재 추가하는 설계·점검·작업표 스크립트는 T3 도구입니다. 해커톤이라는 이유로 신규 앱을 T3로 분류하지 않습니다. 이번 커밋은 제품 스캐폴딩을 생성하지 않습니다.

| 층 | 공통 표준의 방향 | 이번 설계 |
|---|---|---|
| FE | Next.js App Router·React·TypeScript strict·정적 출력 | 유지. package/lock 버전은 스캐폴딩 시 원본 템플릿과 보안 업데이트 확인 후 고정 |
| BE | Connexion 3 AsyncApp·handler/service/repository·OpenAPI | 유지. fixture/live 공급자를 같은 계약에 연결 |
| 로컬·이식 | Python 3.12·uv, Mangum·SAM 경계 | BE 구현 시 유지. 실제 AWS 배포는 현재 요청 범위 아님 |
| 인증 | Azure AD / 서버 검증 | live 서비스 공개 전 별도 통과 필요. P0 합성 fixture 데모는 고객 데이터·서버 쓰기 없음 |
| 배포 | 표준은 AWS 이식 경계 포함 | 사용자 요청 대상은 Vercel. FE 연결부터 검증, BE 런타임·인증 호환성은 H02에서 실측 |
| 데모 백업 | 일회성 HTML 가능 | 킷 build_starter.py 출력은 오프라인 백업으로 보존 |

표준 근거: 이 PC `.claude/rules/tech-stack-standard.md`와 `75_하네스_클라우드배포/00_표준/00_우리표준_SSOT.md` §1. 다른 PC에 사내 템플릿·레지스트리 권한이 없을 수 있으므로 사전 준비에서 그 유무를 확인합니다. 사내 문서·패키지를 외부 저장소에 통째로 복사하지 않습니다.

Vercel은 사용자가 지정한 호스팅입니다. 현재 증거는 CLI 59.23.2 설치와 `vercel whoami`의 login_required 결과, 사용자 제공 g-23 관리자 권한 안내입니다. 실제 프로젝트·team·런타임 호환은 아직 검증되지 않았습니다. 이 카드는 호환성 성공 판정을 대신하지 않습니다.

H02에서 실제 BE 호스팅이 불가능하면 오류·재현 명령을 남기고, P0 fixture FE 배포 / 로컬 BE 시연 / 표준 클라우드 BE 중 허용된 안을 결정합니다. 이탈이 필요하면 실행 증거와 해제 조건을 추가한 뒤 구현합니다. 운영 전환 시에는 합성 데모 범위를 벗어나므로 인증·영속성·클라우드 표준을 다시 검토합니다.
